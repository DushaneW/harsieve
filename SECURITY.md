# Security

This is an initial implementation, not an independently audited sanitizer.
See docs/privacy.md for the precise retention policy and threat boundaries.

Use GitHub private vulnerability reporting when enabled. If unavailable, open
an issue requesting a private contact channel without exploit details or sensitive
data. Do not attach real HAR captures to public issues. Use synthetic canaries
and minimal reproductions instead.

Only the current development line is maintained. There is no guaranteed response
time or published security-support lifecycle.
